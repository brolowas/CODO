# CODO
KODO — бесплатная мобильная IDE для Android. Пиши и редактируй HTML, CSS и JavaScript прямо на смартфоне. Подсветка синтаксиса, автосохранение, предпросмотр проектов, управление файлами, поиск по коду и удобные темы оформления. Современный минималистичный интерфейс, плавные анимации и оптимизация для мобильных устройств. Программируй где угодно!
